## 🧠 Sample Program

```c
#include <stdio.h>

int main() {
    int arr[5] = {1,2,3,4,5};
    int sum = 0;

    for(int i = 0; i < 5; i++) {
        sum += arr[i];
    }

    printf("Sum = %d", sum);
    return 0;
}
